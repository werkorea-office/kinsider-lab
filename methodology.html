Methodology

How the numbers are made

Source

All figures come from Naver DataLab Shopping Insight, which reports the relative volume of shopping-search clicks on Naver, Korea's largest search and shopping platform, within a product category (for example “화장품/미용”, cosmetics & beauty). We request daily data for a fixed watchlist of Korean search terms, every day, automatically.

Demand index

Naver returns values relative to the highest point inside each request, so raw numbers from different requests cannot be compared. Every request we send therefore includes the same baseline term (Sunscreen for beauty, Ramyeon for food). We rescale each request so that the baseline's 8-week average equals 100. A term with an index of 50 drew about half as many shopping-search clicks as the baseline over the last 7 days.

Momentum

Momentum compares a term's average index over the most recent 7 days with its average over the 28 days before. Terms whose demand index is below 10 are left out of the rising and cooling rankings and the headline, because small volumes produce large, misleading percentage swings. Their data is still archived.

What this is not

  • It is not sales data and not a count of searches. It shows relative interest.
  • It covers search terms (categories and ingredients), not individual products or brands.
  • It reflects Naver users in Korea; other channels can behave differently.

Integrity rules

  • No number is written by hand or by AI. Text on this site is produced from the data by fixed templates.
  • If the data source fails on a given day, we show the last verified data with its real date, never a filled-in value.
  • Every daily brief is archived with its raw data file so past calls can be checked.

Watchlist

The current watchlist is public: watchlist.json. Terms are added as new categories and ingredients emerge.
